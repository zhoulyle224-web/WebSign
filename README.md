# WebSign — INTERLINKED Art Direction V2

多页面游戏美术风格展示站，围绕 **Geometric Abstract / Low Poly / Constructivism / Japanese Illustration** 建立统一视觉语言。

## Pages
- `index.html` — Home / Entrance
- `systems.html` — SIGNAL / RELIC 两套视觉系统
- `environment.html` — Environment / 空间舞台
- `character.html` — Character / 完整、切片、低多边形、线稿、剪影状态
- `combat.html` — Combat / 横向拖拽战斗蒙太奇
- `interface.html` — Interface & VFX / HUD 作为构成元素
- `process.html` — Process / 纸张、错版、构成主义拼贴

## Interaction
- 右上角可切换 `SIGNAL` / `RELIC`，主题会通过 `localStorage` 跨页面保持。
- 菜单按钮打开全站多页面导航。
- Combat 页面支持鼠标滚轮与拖拽横向浏览。
- Character 页面支持五种角色表现状态切换。
- 支持 `prefers-reduced-motion`。

## Run
直接打开 `index.html` 即可，无需构建工具与外部依赖。
