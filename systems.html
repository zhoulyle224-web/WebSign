01 / Shared Visual Grammar

ONE SYSTEM.
TWO STATES.

SIGNAL 与 RELIC 共享同一品牌骨架，但在色彩、构图密度、字体角色、材质和时间节奏上保持真正差异，而不是简单换色。

SIGNAL / 信号体

Cold.
Spatial.
Precise.

深黑作为空间，银白作为主体，钴蓝只负责信号、阅读路径与交互焦点。画面更像正在生成的空间装置。

01ASSEMBLE / 几何碎片聚合
02SCAN / 蓝色信号沿轴线显影
03PARALLAX / 人物与结构分层移动
04EXTEND / 圆弧、轴线、定位块延展
RELIC / 遗构体

Narrative.
Printed.
Broken.

黑褐与旧纸白交替，暗红大圆与巨大衬线字承担叙事锚点。人物、照片、场景和文字被切割、错版、重组。

01MISREGISTER / 短暂错版后重新对齐
02TEAR / 图片像纸张被撕开
03COLLAGE / 文本与图像重组
04JUMP CUT / 胶片式跳帧切换
SHARED / CORE RULES

SAME DNA.
DIFFERENT TEMPO.

01

Asymmetry

避免传统居中产品页。主体压向结构交点，留出主动的空白区域。

02

Scale Conflict

超大圆弧、文字与微型编号并置，制造游戏世界的尺度感。

03

Interlock

人物、文字、几何与场景互相遮挡，不再被分离成普通卡片。

04

Motion Focus

强动效只放在进入、切换、战斗和项目打开等关键节点。
