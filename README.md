# INTERLINKED Art Direction Web Prototype

A self-contained interactive art-direction showcase built around two visual systems:

- **SIGNAL** — cold, spatial, geometric, scanning/assembly motion language.
- **RELIC** — narrative, retro, constructivist collage, misregistration/cut-and-recompose language.

## Run
Open `index.html` directly in Chrome/Edge. No build step and no external assets are required.

## Controls
- Switch **SIGNAL / RELIC** in the top-right corner.
- Scroll through sections.
- In **COMBAT**, use mouse wheel or drag horizontally.
- Motion is reduced automatically when `prefers-reduced-motion` is enabled.
